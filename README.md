# Dune RTS — War for Spice

Браузерная RTS-игра в стиле классической Dune II / Command & Conquer, написанная на Next.js 16 + TypeScript + Canvas. Полностью процедурная графика — все тайлы, здания, юниты и эффекты рисуются кодом, без внешних ассетов.

![Dune RTS](https://img.shields.io/badge/Next.js-16-black) ![TypeScript](https://img.shields.io/badge/TypeScript-5-blue) ![Canvas](https://img.shields.io/badge/Canvas-2D-orange)

## Возможности

### Игровой процесс
- **2 фракции**: Атрейдес (синий, игрок) против Харконнен (фиолетовый, ИИ)
- **3 уровня сложности**: Лёгкий / Средний / Тяжёлый
- **Условие победы**: уничтожить дворец врага
- **Поражение**: потерять свой дворец

### Рельеф (8 типов, бесшовный)
Бесшовная отрисовка рельефа через per-pixel world-space шум — квадраты тайлов не видны:
- **Песок** — проходим, можно строить
- **Дюны** — проходим, рябь
- **Скала** — непроходим, можно строить
- **Горы** — непроходим, нельзя строить
- **Спайс** — оранжевые поля на песке, ресурс
- **Богатый спайс** — больше ресурса
- **Вода** — непроходима, анимированные волны

### Здания (полудиметрия 3D)
Все здания — 3D-диметрические структуры (ромбовидное основание + стены + крыша):

| Здание | Размер | Стоимость | Энергия | Описание |
|--------|--------|-----------|---------|----------|
| **Дворец** | 2×2 | — | +6 | Главная база, создаёт доставщиков |
| **Генератор** | 2×2 | 120 | +12 (×уровень) | Энергия, апгрейд до ур.3 |
| **Казармы** | 2×2 | 150 | 3 | Создаёт солдат |
| **Фабрика** | 3×2 | 300 | 5 | Создаёт танки |
| **Турель** | 1×1 | 100 | 2 | Автозащита, радиус 4.5 |
| **Спайс-завод** | 2×2 | 200 | 2 | Переработка спайса → кредиты |
| **Радар** | 2×2 | 180 | 3 | Открывает туман войны (R12) |

### Юниты
| Юнит | Стоимость | HP | Скорость | Урон | Дальность |
|------|-----------|-----|----------|------|-----------|
| **Доставщик** | 150 | 200 | 0.08 | — | — |
| **Солдат** | 60 | 70 | 0.12 | 9 | 1.8 |
| **Танк** | 200 | 160 | 0.09 | 22 | 2.8 |

- **8-направленные спрайты** для техники (поворот по направлению движения)
- **1 юнит на тайл** — без stacking
- **BFS pathfinding** — обход препятствий

### Энергосистема
- Генераторы производят энергию (12 × уровень)
- Здания/юниты потребляют энергию
- Без энергии — производство и турели не работают
- **Апгрейд генератора**: 3 уровня, +12 энергии за уровень

### Туман войны
- 3 состояния: не разведано / разведано / видно сейчас
- Юниты и здания открывают область по радиусу обзора
- **Радар** открывает 12 тайлов (vs 3-5 у обычных зданий)

### Исследования (5 апгрейдов)
- **Турель**: +50% урон, +30% радиус
- **Казарма**: +40% скорость юнитов, +30% HP
- **Фабрика**: +50% урон танков

### Червь Шай-Хулуд
- Появляется редко (каждые 3500 тиков) — эффект неожиданности
- **Только по песку** (не лезет на скалы/воду)
- Съедает **максимум 2 юнита**, потом исчезает
- Можно уничтожить (120 HP)

### Визуальные эффекты
- Снаряды с трассирующим следом
- Взрывы (радиальный градиент + искры)
- Вспышки выстрелов
- Индикатор радиуса атаки у турелей/юнитов
- Постепенная разгрузка харвестеров (+кредиты в реальном времени)

### Retro CRT-эффект 80х
- Сканлайны
- Виньетка
- Тёплый amber color grade
- Phosphor mask (RGB-полосы)
- Лёгкое мерцание

## Экономика

1. **Доставщик** едет к спайсу, добывает его (cargo до 60)
2. Возвращается на **спайс-завод** (только туда!)
3. Разгружается **постепенно** — +40$ за тик, видно в реальном времени
4. Если спайс-завода нет — ждёт у дворца
5. Если завод занят — ждёт в очереди

## Архитектура

```
src/
├── app/
│   ├── page.tsx          # UI: меню, редактор, игра (React)
│   ├── layout.tsx        # Layout + Toaster
│   └── globals.css       # CRT-оверлей, стили
├── lib/
│   ├── tile-renderer.ts  # Процедурная графика (тайлы, здания, юниты)
│   └── game-engine.ts    # Игровая логика (юниты, ИИ, бой, экономика)
└── components/ui/         # shadcn/ui компоненты
```

### tile-renderer.ts
- Бесшовный рельеф через fbm noise (per-pixel)
- Диметрические здания (ромб + стены + крыша)
- 8-направленные спрайты техники (кэширование)
- Эффекты: снаряды, взрывы, вспышки, fog of war
- Кэширование canvas для производительности

### game-engine.ts
- Игровой цикл (10 тиков/сек)
- BFS pathfinding с обходом препятствий
- 1 юнит на тайл (anti-stacking)
- ИИ Харконнен: экономика, постройка, атаки, защита
- Энергосистема, исследования, апгрейды
- Fog of war, черви, снаряды/взрывы

## Производительность

- **Terrain кэшируется** в offscreen canvas — перерисовка только при смене тайлов
- **Fog of war** обновляется каждые 5 тиков
- **React re-render** каждые 3 тика (canvas через rAF независимо)
- **Спрайты кэшируются** — 8 направлений × 2 фракции × 3 юнита
- Результат: 11 тиков/сек плавно

## Установка и запуск

```bash
# Установка зависимостей
bun install

# Запуск dev-сервера (порт 3000)
bun run dev

# Проверка линта
bun run lint
```

Откройте http://localhost:3000 в браузере.

## Скриншоты

Игра запускается из меню → выбор сложности → "Сражение".

1. **Меню**: выбор сложности, кнопки "Сражение" / "Редактор"
2. **Редактор**: кисть/заливка/прямоугольник, палитра тайлов, генератор карт
3. **Игра**: HUD (кредиты, энергия, армия), меню строительства, журнал событий
4. **Бой**: снаряды, взрывы, радиусы атаки, fog of war
5. **Победа/поражение**: экран с результатом
